# velo Documentation

Guides for installing, using, configuring, and developing velo.

## Start here

New to velo? Read these in order:

1. [Set up velo](setup.md). Install a binary or build from source.
2. [Quick start](../README.md#quick-start). Store and run your first macro.
3. [Commands](commands.md). Learn the commands you will use every day.
4. [Keybindings](keybindings.md). Learn the TUI.
